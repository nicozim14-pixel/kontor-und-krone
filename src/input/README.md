# input – Eingaben per Finger

Übersetzt Tippen, Wischen und Zoomen in Spieler-Aktionen.
Das Spiel ist ein reines Tablet-Spiel (E-012). Maus-Eingaben funktionieren technisch mit, weil Claude sie für die eigenen Tests braucht (E-013).

- Bereits hier: `browserGestures.ts` – unterbindet störende Browser-Gesten (Seiten-Zoom, Kontextmenü).
- Die richtige Spiel-Steuerung (Kamera, Bauen, Straßen ziehen) kommt in Phase 2.
