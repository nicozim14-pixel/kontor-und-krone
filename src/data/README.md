# data – die Spieldaten

Waren, Gebäude, Produktionsketten, Bevölkerungsstufen usw. stehen als Datendateien (JSON) hier, nicht im Code.
Beim Laden wird jede Datei mit einem Prüfschema kontrolliert, damit Tippfehler sofort mit einer deutschen Fehlermeldung auffallen.

- Entspricht den „ScriptableObjects“ aus dem Unity-Masterplan.
- Format, Prüfwerkzeug und genauer Ablageort werden in Unterphase 1.6 festgelegt.
