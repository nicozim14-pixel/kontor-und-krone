# sim – die Spiellogik (Simulation)

Hier wird das Spiel „gerechnet“: Waren, Gebäude, Produktion, Bevölkerung, Handel.

- **Wichtigste Regel:** Die Simulation weiß nichts von der Grafik. Kein Babylon.js in diesem Ordner.
  So bleibt sie schnell, leicht zu testen, und Spielstände lassen sich einfach speichern.
- Wird in Unterphase 1.6 geplant. Der erste Inhalt kommt mit dem Durchstich in 1.7 (Test-Ware „Holz“).
